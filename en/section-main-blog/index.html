    Blog Page Template¶

    The Blog Page template displays a collection of blog posts with optional sidebar, search functionality, and tag filtering. This is the main page customers see when accessing your blog.

    This is a template section that controls the layout and features of your blog listing page.

    Important Note¶

    This template only appears on blog pages. You customize it by: 1. Going to your Theme Editor 2. Navigating to any blog page (or selecting "Blog" > "Default blog") 3. Adjusting the Blog pages section settings

    Blog posts themselves are managed in Online Store > Blog Posts in your Shopify admin.

    Template Settings¶

    Colors & Layout¶

    • Color scheme — Choose the background color for the blog header area. Default: Scheme 1.
    • Articles color scheme — Choose the color scheme specifically for article cards and sidebar. Default: Scheme 1.

    Tip: Using different color schemes for the header and articles can create nice visual separation.

    Display Options¶

    • Articles per page — How many blog posts to show before pagination. Range: 1-50 articles. Default: 24.

    Note: More articles per page means fewer clicks, but longer page load times. 12-24 is usually optimal.

    Sidebar¶

    • Show sidebar — Enable to display a sidebar with tags and search functionality. Default: Enabled.

    Sidebar contents (when enabled): - Tag cloud for filtering posts by topic - Article search box

    Layout: - With sidebar: Articles display in 3 columns (desktop), sidebar on left - Without sidebar: Articles display in wider grid across full width

    Blog Header¶

    • Heading — Main title for your blog. Default: Uses your blog's name (e.g., "{{ blog.title }}").

    • Heading tag — HTML tag for SEO (H1-H6 or Span). Default: H1.

    • Tip: Use H1 for your blog title for proper SEO structure.

    • Heading size — Visual size of the heading:

    • Title 1 — Largest
    • Title 2 — Large
    • H1-H6 — Standard sizes

    Default: H1.

    • Heading font weight — Text thickness. Range: 100 (thin) to 900 (bold). Default: 700 (bold).

    • Introduction — Optional introductory text explaining what your blog is about.

    Sidebar Settings (when enabled)¶

    • Show blog tags — Enable to display tag cloud in sidebar. Default: Enabled.

    • Blog tags title — Heading for the tags section. Default: "Topics" or similar.

    • Show search box — Enable article search functionality in sidebar. Default: Enabled.

    • Search box title — Heading for the search section. Default: "Search Articles" or similar.

    Spacing¶

    • Margin top — Space above the section. Options: Standard or None. Default: Standard.
    • Margin bottom — Space below the section. Options: Standard or None. Default: Standard.
    • Padding top — Inner spacing at the top. Options: Standard or None. Default: Standard.
    • Padding bottom — Inner spacing at the bottom. Options: Standard or None. Default: Standard.

    Blog Management¶

    Creating and Managing Blogs¶

    Blogs are managed in your Shopify admin:

    1. Go to Online Store > Blog Posts
    2. Click Manage blogs to create or edit blogs
    3. Click Add blog to create a new blog
    4. Name your blog (e.g., "News", "Guides", "Company Blog")
    5. Add SEO details
    6. Save

    Creating Blog Posts¶

    To add articles to your blog:

    1. Go to Online Store > Blog Posts
    2. Select the blog you want to add to
    3. Click Add blog post
    4. Enter:
    5. Title — Post headline
    6. Content — Article body (use rich text editor)
    7. Excerpt — Short summary (appears in article cards)
    8. Featured image — Main image (recommended: 1200x800px)
    9. Author — Writer name
    10. Tags — Topics for organization and filtering
    11. SEO — Meta description and URL handle
    12. Set visibility (published, hidden, or scheduled)
    13. Save

    Tags¶

    Tags help organize your blog posts and allow customers to filter by topic.

    Adding tags to posts: 1. Edit a blog post in your Shopify admin 2. Scroll to the "Organization" section 3. Add tags (e.g., "tutorials", "news", "product updates") 4. Save

    How tags work: - Tags appear as clickable badges in the sidebar - Customers can click a tag to see all posts with that tag - Tags in URLs show as: /blogs/blog-name/tagged/tag-name

    Tag best practices: - Use consistent, lowercase tags - Create 5-10 main tags, not hundreds of unique tags - Think about topics customers would want to browse

    Search Functionality¶

    The sidebar search box allows customers to search articles by keywords:

    • Searches article titles, content, and excerpts
    • Results show relevant posts ranked by relevance
    • Search is case-insensitive
    • Returns published posts only

    Pagination¶

    When you have more articles than the "per page" setting: - Pagination controls appear at the bottom - Customers can navigate between pages - URL changes to include page number - SEO-friendly pagination links

    Usage Tips¶

    • Sidebar or no sidebar:
    • Use sidebar if you have many posts across multiple topics (helps with navigation)

    • Skip sidebar for cleaner look if you have fewer posts or prefer minimalism

    • Featured images: Always add high-quality featured images to blog posts. They're crucial for visual appeal in the grid layout.

    • Consistent image sizes: Use the same aspect ratio for all blog featured images (16:9 or 4:3 recommended) for a uniform grid.

    • Compelling excerpts: Write custom excerpts for each post. These appear in article cards and influence click-through rates.

    • Tags organization: Use tags strategically as navigation categories, not just keywords. Examples:

    • "How-to"
    • "Product News"
    • "Customer Stories"

    • "Industry Insights"

    • Regular publishing: Maintain an active blog with regular posts. Aim for at least one post per month minimum.

    • Mobile experience: The grid adjusts to 2 columns on mobile. Test to ensure article cards remain readable and images look good.

    • Blog introduction: Use the introduction text to set expectations about what customers will find in your blog.

    Best Practices¶

    • Content strategy: Plan blog topics that:
    • Answer customer questions
    • Showcase product usage
    • Provide value beyond selling
    • Target relevant SEO keywords

    • Establish your expertise

    • Visual quality: Use professional, consistent imagery. Poor images hurt your brand.

    • Post structure: Format blog posts with:

    • Clear headings and subheadings
    • Short paragraphs (2-4 sentences)
    • Bullet points for lists
    • Images throughout longer posts

    • Call-to-action at the end

    • SEO optimization:

    • Write descriptive titles (50-60 characters)
    • Add meta descriptions (150-160 characters)
    • Use relevant keywords naturally
    • Add internal links to products or other posts

    • Optimize images with alt text

    • Engagement: Enable comments if you want customer interaction. Respond to comments promptly.

    • Promotion: Share blog posts on:

    • Social media
    • Email newsletters
    • Homepage (use Articles section)
    • Product pages (if relevant)

    Multiple Blogs¶

    You can create multiple blogs for different purposes:

    • News blog — Company updates and announcements
    • How-to blog — Tutorials and guides
    • Customer stories — Testimonials and case studies
    • Industry blog — Trends and insights

    Each blog gets its own URL and can be displayed separately on your site.
