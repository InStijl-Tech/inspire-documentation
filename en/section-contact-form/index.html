    Contact Form Section¶

    The Contact Form section provides a flexible, customizable contact form for your store. You can add various form fields, customize the layout, and make it easy for customers to get in touch with you.

    Use this section to: - Create a custom contact page - Collect customer inquiries and feedback - Gather leads with specific information - Provide customer support options - Build custom forms for different purposes

    Adding and Managing This Section¶

    This section can be added to most pages in your store. To learn how to add, remove, or reorder sections on your page, please refer to Shopify's official guide on Using sections and blocks.

    Section Settings¶

    Layout¶

    • Color scheme — Choose the color scheme for the section background. Default: Scheme 2.
    • Card color scheme — Choose the color scheme specifically for the form container/card. Default: Scheme 1.
    • Section type — Choose the section width:
    • Edge to Edge — Section extends to screen edges
    • Box — Section stays within a container

    Default: Box. * Margin top — Control the top margin. Choose between Auto or None. * Margin bottom — Control the bottom margin. Choose between Auto or None. * Padding top — Control the internal top padding. Choose between Auto or None. * Padding bottom — Control the internal bottom padding. Choose between Auto or None.

    Text Settings¶

    • Text alignment — Choose Left, Center, or Right alignment for the section heading and text. Default: Left.
    • Heading — The main heading above the form. Default: "Contact".
    • Heading tag — Choose the HTML tag for SEO (H1, H2, H3, H4, H5, H6, or span). Default: span.
    • Heading size — Choose the visual size for the heading. Default: H3-size.
    • Heading font-weight — Choose Normal or Bold. Default: Bold.
    • Intro Text — Add introductory text that appears above the form, explaining why customers should contact you or what to expect. Supports rich text.

    Blocks¶

    Build your form by adding different block types. Each block represents a form field or element.

    Heading Block¶

    Add a heading within the form (different from the main section heading).

    Settings: * Heading — The heading text. Default: "Contact Us". * Heading Tag — Choose the HTML tag (H1-H6 or span). Default: span. * Heading Size — Choose the visual size. Default: H3-size. * Heading font-weight — Choose Normal or Bold. Default: Bold.

    Name Input Block¶

    Add a name field to your form. Limited to one per form.

    Settings: * Required — Enable to make this field mandatory. Default: Disabled.

    Email Input Block¶

    Add an email address field to your form. Limited to one per form.

    This block has no additional settings — it's automatically configured as an email input.

    Input Field Block¶

    Add a custom text input field. You can add multiple input blocks for different information.

    Settings: * Name — The internal field name (used for form processing). Default: "unique_field_name". Make this unique for each field. * Label — The label shown to customers above the field. Default: "Your input". * Input Placeholder — Placeholder text shown inside the empty field. Default: "Enter your input". * Required — Enable to make this field mandatory. Default: Disabled. * Input Type — Choose the type of input: - Text — Regular text input - Email — Email address (with validation) - Phone — Phone number - Number — Numeric input only

    Message Input Block (Textarea)¶

    Add a large text area for longer messages or comments.

    Settings: * Required — Enable to make this field mandatory. Default: Disabled. * Textarea Rows — Control how tall the text area is. Range: 2-10 rows. Default: 4 rows.

    Submit Button Block¶

    Add the form submit button. Limited to one per form.

    Settings: * Button Text — The text shown on the submit button. Default: "Submit". * Button Icon — Add an optional icon to the button (None, Chevron Right, Arrow Circle Right, or Arrow Right).

    Default Form Setup¶

    When you add this section, it includes a ready-to-use contact form with: - Heading: "Get in Touch" - Name field (required) - Email field - Phone field (optional) - Message textarea (required) - Submit button: "Send Message"

    You can customize this by adding, removing, or rearranging blocks.

    Usage Tips¶

    • Required fields: Mark essential fields as required to ensure you get the information you need. At minimum, make email and message fields required.

    • Field names: When adding custom Input Field blocks, give each one a unique name (e.g., "company", "subject", "order_number"). This helps you identify the information when you receive form submissions.

    • Form submissions: Form submissions are sent to the email address specified in your Shopify admin under Settings > General > Store contact email.

    • Privacy note: If you collect personal information, mention your privacy policy in the intro text. This builds trust and may be legally required in some regions.

    • Keep it simple: Don't ask for too much information. The more fields you add, the less likely customers are to complete the form. Focus on essential fields only.

    • Mobile friendly: The form automatically adjusts for mobile devices. Test it on different screen sizes to ensure a good experience.

    • Custom forms: Use this section to create specialized forms beyond basic contact:

    • Wholesale inquiry forms (with company name, tax ID, etc.)
    • Custom order request forms
    • Partnership inquiry forms
    • Product feedback forms
