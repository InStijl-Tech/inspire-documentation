    Cart Page Template¶

    The Cart Page template displays the shopping cart where customers review items, adjust quantities, and proceed to checkout. This is a crucial page in the purchase flow.

    Template Settings¶

    Colors & Layout¶

    • Color scheme — Background color for the cart page. Default: Scheme 1.
    • Card color scheme — Color scheme for individual cart item cards. Default: Scheme 2.
    • No margin bottom — Remove bottom spacing. Default: Enabled.

    Heading¶

    • Heading — Cart page title. Default: "Shopping Cart".
    • Heading tag — HTML tag (H1-H6). Default: H1.
    • Heading size — Visual size (Title 1, Title 2, H1-H6). Default: H1.
    • Heading font weight — Text thickness (100-900). Default: 700.
    • Content — Optional description text below heading.

    Cart Items Display¶

    • Item image size — Size of product thumbnails (pixels). Range: 50-200px. Default: 100px.
    • Item title size — Product name text size. Default: H5.
    • Item title font weight — Product name thickness (100-900). Default: 700.

    Empty Cart¶

    • Empty cart heading — Title shown when cart is empty. Default: "Your cart is empty".
    • Empty cart heading size — Size of empty message. Default: H3.
    • Empty cart heading font weight — Thickness (100-900). Default: 700.
    • Empty cart content — Description when cart is empty.

    Cart Features¶

    For Each Item:¶

    • Product image (clickable to product page)
    • Product name and variant
    • Individual price
    • Quantity adjuster (+ / - buttons or trash icon if qty = 1)
    • Line total (price × quantity)
    • Expandable details (variants, options)

    Cart Summary (Sidebar):¶

    • Subtotal
    • Estimated taxes
    • Shipping calculation
    • Total
    • Checkout button
    • Payment icons
    • Trust badges/USPs

    Blocks¶

    USP Block¶

    Add trust signals in the cart sidebar: * Icon — Font Awesome icon (e.g., fa-solid fa-lock). * Icon color — Choose icon color. * Text — USP message (e.g., "Secure Checkout"). * No margin bottom — Remove spacing below USP.

    App Block¶

    Integrate third-party apps (discount codes, upsells, etc.).

    Usage Tips¶

    • Clear CTAs: Make the checkout button prominent and easy to find.
    • Trust signals: Add USPs like "Secure Checkout", "Free Shipping", "Easy Returns".
    • Empty cart: Provide clear next steps with "Continue Shopping" button.
    • Mobile: Test quantity adjusters work well on touchscreens.
    • Shipping calculator: Consider adding estimated shipping costs.

    Best Practices¶

    • Keep the cart simple and focused on checkout
    • Show item images so customers can verify their selections
    • Make quantity adjustment intuitive
    • Display total costs clearly (subtotal, taxes, shipping, total)
    • Include trust badges to reduce checkout anxiety
    • Optimize for mobile—most cart abandonment happens on mobile
