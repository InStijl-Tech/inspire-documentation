    Breadcrumbs Section¶

    The Breadcrumbs section displays a navigation path showing customers where they are within your store's hierarchy. It helps with both navigation and SEO by showing the page structure.

    Breadcrumbs appear automatically on most pages (except the homepage and 404 page) and show the path from home to the current page.

    What Are Breadcrumbs?¶

    Breadcrumbs are a navigation aid that shows the current page's location in the site hierarchy. They typically look like:

    Home > Collections > Women's Clothing > Summer Dresses

    Customers can click any part of the breadcrumb trail to navigate back up the hierarchy.

    Adding or Managing the Section¶

    1. From your Shopify admin, go to Online Store > Themes
    2. Click Customize on your current theme
    3. Navigate to any page (not the homepage)
    4. Look for the Breadcrumbs section near the top of the page
    5. Click on it to adjust settings

    Note: Breadcrumbs automatically appear on all pages except the homepage and 404 page. You don't need to manually add them to each page.

    Section Settings¶

    Colors¶

    • Color scheme — Choose the background color and text style for the breadcrumbs. Default: Scheme 1.

    That's it! Breadcrumbs are simple by design. The trail is automatically generated based on the page structure.

    How Breadcrumbs Work on Different Pages¶

    The breadcrumb trail changes automatically depending on the page type:

    Product Pages¶

    Home > Collection Name > Product Name

    If a customer arrived from a collection, that collection is included in the breadcrumb trail.

    Collection Pages¶

    Home > Collection Name

    If the collection has active tag filters: Home > Collection Name > Tag Name

    Blog Pages¶

    Home > Blog Name

    With tag filters: Home > Blog Name > Tag Name

    Article Pages¶

    Home > Blog Name > Article Title

    Regular Pages¶

    Home > Page Title

    Cart Page¶

    Home > Cart

    List Collections Page¶

    Home > Collections

    Benefits of Breadcrumbs¶

    For Customers:¶

    • Easy navigation — Quickly go back to higher-level pages
    • Context — Understand where they are in the site structure
    • Reduced clicks — Jump directly to any level in the hierarchy

    For Your Store:¶

    • SEO improvement — Search engines use breadcrumbs to understand site structure
    • Lower bounce rate — Customers can easily explore related pages
    • Professional appearance — Shows site organization and attention to detail

    Usage Tips¶

    • Styling: Choose a color scheme that contrasts subtly with your page background. Breadcrumbs should be visible but not dominate the page.

    • Mobile layout: Breadcrumbs automatically adjust for mobile devices. They may wrap to multiple lines if the path is long—this is normal.

    • Collection context: When customers browse from a collection to a product, the collection appears in the breadcrumb. This encourages them to return to browsing that collection.

    • SEO benefits: Keep breadcrumbs enabled for better search engine visibility. They help Google understand your site structure.

    • Position: Breadcrumbs typically appear near the top of the page, below the header but above the main content. This is the standard position customers expect.

    Best Practices¶

    • Don't hide breadcrumbs: Unless you have a specific reason, keep breadcrumbs visible. They're a standard navigation element customers expect.

    • Page titles matter: Since breadcrumbs use your page titles, make sure titles are:

    • Clear and descriptive
    • Not too long (breadcrumbs can wrap awkwardly with very long titles)

    • Accurately represent the page content

    • Collection names: Use descriptive collection names like "Women's Shoes" rather than generic names like "Collection 1"—these appear in breadcrumbs.

    • Test the paths: Navigate through your store and verify breadcrumb trails make sense and help customers understand where they are.

    • Consistent structure: Organize your collections and products logically so breadcrumb trails reflect an intuitive hierarchy.

    Accessibility¶

    Breadcrumbs include proper accessibility markup: - Wrapped in a <nav> element with role="navigation" - Include aria-label="breadcrumb" for screen readers - Mark the current page with aria-current="page"

    This helps customers using assistive technologies navigate your store.

    Technical Details¶

    Automatic Display¶

    Breadcrumbs are automatically: - Hidden on homepage (no breadcrumb needed) - Hidden on 404 pages (path doesn't apply) - Displayed on all other page types

    Dynamic Generation¶

    The breadcrumb trail is generated dynamically based on: - Current page type and template - Collection context (if arriving from collection) - Active tags or filters - URL structure

    You don't need to manually configure breadcrumbs for each page—the theme handles this automatically.

    Customizing Breadcrumb Text¶

    While breadcrumb labels are mostly automatic, you can influence them by:

    • Collection titles — Edit in Products > Collections
    • Product titles — Edit in Products
    • Page titles — Edit in Online Store > Pages
    • Blog titles — Edit in Online Store > Blog Posts > Manage blogs
    • Article titles — Edit individual blog posts

    Breadcrumbs use these titles directly, so clear, concise titles work best.

    Removing Breadcrumbs¶

    If you want to remove breadcrumbs from your store:

    1. In the Theme Editor, navigate to any page where breadcrumbs appear
    2. Click on the Breadcrumbs section
    3. Click Remove section (trash icon)
    4. Save your changes

    Note: Removing breadcrumbs impacts navigation and SEO. Only remove them if you have a specific reason.

    SEO Benefits¶

    Breadcrumbs provide SEO value by: * Creating a clear site hierarchy for search engines * Generating additional internal links * Appearing in Google search results (breadcrumb markup) * Reducing bounce rate (easier navigation) * Improving page authority distribution

    Most SEO experts recommend keeping breadcrumbs enabled for these benefits.
