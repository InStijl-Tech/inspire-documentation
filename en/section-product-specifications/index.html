    Product Specifications Section¶

    The Product Specifications section displays technical details, features, and specifications for your products in a clean, organized table format. It's perfect for showing product dimensions, materials, compatibility, technical specs, and other structured information.

    This section helps customers find specific product details quickly and makes informed purchase decisions.

    Important Note¶

    This section only appears on product pages. You customize it by: 1. Going to your Theme Editor 2. Navigating to any product page (or selecting "Products" > "Default product") 3. Finding the Product Specifications section 4. Adding specification rows with labels and values

    Section Settings¶

    Layout¶

    • No margin bottom — Enable to remove bottom spacing below this section. Default: Enabled.

    • Color scheme — Choose the background color and text style. Default: Scheme 1.

    Text Settings¶

    • Text alignment — Align the section content:
    • Left — Left-aligned (recommended for specifications)
    • Center — Centered
    • Right — Right-aligned

    Default: Left.

    Section Layout¶

    The section displays: - Left side: Product's featured image (4 columns on desktop) - Right side: Specifications table in a card (8 columns on desktop)

    On mobile, these stack vertically with the image on top.

    Blocks¶

    Title Block¶

    Add an optional title above the specifications table. Limit: 1 title block.

    Settings:

    • Heading — The title text to display. Default: "Specifications".

    • Heading tag — Choose the HTML tag for SEO:

    • H1-H6 — Standard heading tags
    • Span — Not a heading (for styling only)

    Default: H2.

    • Heading size — Control the visual size:
    • Title 1 — Largest
    • Title 2 — Large
    • H1-H6 — Standard sizes

    Default: H2.

    • Heading font weight — Text thickness. Range: 100 (thin) to 900 (bold). Default: 700 (bold).

    Row Block¶

    Add specification rows to create your table. Each row has a label and a value.

    Settings for each Row:

    • Label — The specification name (appears in bold on the left). Examples:
    • "Dimensions"
    • "Weight"
    • "Material"
    • "Color"

    • "Warranty"

    • Value — The specification detail (appears on the right). Examples:

    • "10 x 5 x 3 inches"
    • "2.5 lbs"
    • "Stainless steel"
    • "Matte black"
    • "2 years limited"

    Add as many row blocks as you need to list all specifications.

    HTML Block¶

    Add custom HTML content to the specifications area for more complex formatting needs.

    Settings:

    • Content — Enter your custom HTML code.

    This block is useful for advanced users who want to add custom layouts, embedded content, or special formatting that goes beyond simple specifications.

    Rich Text Block¶

    Add formatted text content using Shopify's rich text editor.

    Settings:

    • Content — Enter formatted text with bold, italic, lists, links, etc.

    Use this for adding paragraphs of context, notes, or disclaimers related to the specifications.

    App Block¶

    Integrate third-party Shopify apps into your specifications area. Apps that support product page blocks will appear as options.

    Usage Tips¶

    • Organization: Group related specifications together:
    • Physical attributes (dimensions, weight, color)
    • Technical specs (power, capacity, compatibility)
    • Materials and construction
    • Care and maintenance

    • Warranty and compliance

    • Consistent formatting: Keep labels and values formatted consistently:

    • Use the same units of measurement throughout
    • Capitalize labels consistently

    • Be precise with values

    • Common specifications to include:

    • Dimensions: Length x Width x Height (with units)
    • Weight: Product weight (shipping weight separate if needed)
    • Materials: What the product is made from
    • Color options: Available colors
    • SKU/Model number: For reference
    • Manufacturer: Brand name
    • Country of origin: Where it's made
    • Warranty: Coverage details

    • Certifications: Safety or quality certifications

    • Image selection: The section uses the product's featured image. Ensure your featured image clearly shows the product.

    • Mobile layout: The two-column layout (image + specs) stacks on mobile. Keep specification values concise so they're easy to read on small screens.

    • Title choice: Use titles like:

    • "Specifications"
    • "Technical Details"
    • "Product Information"

    • "Features & Specs"

    • Don't duplicate description: Keep specifications separate from your product description. Use specifications for factual data, and the description for benefits and storytelling.

    Best Practices¶

    • Be specific: Provide exact measurements and details. Vague specifications don't help customers.

    • Use standard units: Stick to common measurement systems your customers understand (inches or cm, pounds or kg).

    • Include what matters: Focus on specifications customers need to know before buying. Not every detail needs to be listed.

    • Update regularly: Keep specifications current, especially if product materials or features change.

    • Test accuracy: Verify that all specifications are correct. Wrong dimensions or weights can lead to returns and dissatisfied customers.

    • Scannable format: The table format makes specifications easy to scan quickly—keep each row to a single line when possible.

    • Care instructions: Include care, maintenance, or assembly requirements if relevant.

    • Compliance information: Add required safety certifications, age recommendations, or regulatory information.
