    Product Page Setup Guide¶

    This guide will help you create optimized product pages that showcase your products effectively and drive conversions.

    Overview¶

    Product pages are critical for converting visitors into customers. A well-designed product page should:

    • Display product information clearly
    • Show high-quality product images
    • Provide all necessary product details
    • Include social proof (reviews, ratings)
    • Suggest related products
    • Make purchasing easy and intuitive

    Understanding Product Page Structure¶

    Theme InSpire product pages consist of several sections:

    1. Product Template - Main product information and purchase form
    2. Product Description - Detailed product information
    3. Product Specifications - Technical details and attributes
    4. Product Recommendations - Related or complementary products

    Step 1: Configure the Main Product Template¶

    The main product section displays essential product information.

    Access Product Template Settings¶

    1. Go to Online Store > Themes
    2. Click Customize
    3. Navigate to Products > Default product
    4. Click on the Product information section

    Key Settings to Configure¶

    Image Gallery: - Enable/disable image zoom - Set thumbnail position (left, bottom, or hidden) - Configure image aspect ratio - Enable video support

    Product Information: - Show/hide SKU - Display vendor name - Enable dynamic checkout buttons - Configure variant selectors (dropdown or buttons)

    Pricing Display: - Show compare-at prices - Display tax information - Show unit pricing

    Add to Cart: - Customize button text - Enable quantity selector - Configure stock indicators

    For detailed settings, see Product Page Template Documentation.

    Step 2: Set Up Product Description¶

    The description section provides detailed product information.

    Configure Product Description Section¶

    1. In the product template editor, locate Product Description
    2. Configure layout options:
    3. Full width or contained
    4. Background color
    5. Padding and spacing

    Content Best Practices¶

    When writing product descriptions:

    • Be specific: Include measurements, materials, and features
    • Use bullet points: Make key features scannable
    • Tell a story: Connect the product to customer needs
    • Include keywords: Help with SEO
    • Format for readability: Use headings, paragraphs, and lists

    Example Structure: 

    ## About This Product
Brief introduction paragraph

## Key Features
- Feature 1
- Feature 2
- Feature 3

## How to Use
Step-by-step instructions

## Care Instructions
Maintenance information

    For detailed settings, see Product Description Documentation.

    Step 3: Add Product Specifications¶

    Display technical details and specifications.

    Enable Product Specifications¶

    1. In the product template, find Product Specifications
    2. Add specification blocks:
    3. Click Add block
    4. Select Specification item
    5. Add label and value

    Common Specifications¶

    • Dimensions: Size, weight, volume
    • Materials: Fabric, components, composition
    • Care: Washing, maintenance instructions
    • Origin: Made in, brand information
    • Certifications: Quality marks, standards

    Using Metafields¶

    For dynamic specifications:

    1. Set up product metafields in Shopify admin
    2. Link metafields to specification blocks
    3. Specifications will auto-populate per product

    For detailed settings, see Product Specifications Documentation.

    Step 4: Enable Product Recommendations¶

    Show related products to increase average order value.

    Configure Recommendations¶

    1. Locate Product Recommendations section
    2. Configure settings:
    3. Section heading
    4. Number of products to show
    5. Recommendation algorithm (related or complementary)
    6. Display style (carousel or grid)

    Recommendation Types¶

    • Automatic: Shopify's AI suggests related products
    • Manual: Hand-pick related products using metafields
    • Collection-based: Show products from same collection

    For detailed settings, see Product Recommendations Documentation.

    Step 5: Optimize Product Images¶

    High-quality images are crucial for product pages.

    Image Guidelines¶

    Technical Requirements: - Minimum size: 2048 x 2048 pixels - File format: JPG or PNG - File size: Under 2MB (compressed) - Background: White or transparent preferred

    Photography Tips: - Use multiple angles (front, back, sides, details) - Show product in use (lifestyle images) - Include size reference when relevant - Maintain consistent lighting and style - Show color variations accurately

    Upload Images¶

    1. In Shopify admin, go to Products
    2. Select a product
    3. In the Media section, click Add media
    4. Upload images or drag to reorder
    5. Set alt text for SEO and accessibility

    Step 6: Configure Variants¶

    Set up product variants for different options.

    Create Variants¶

    1. In product admin, go to Variants section
    2. Add option names (Size, Color, Material)
    3. Add option values (Small, Medium, Large)
    4. Set pricing per variant
    5. Upload variant-specific images

    Variant Display Options¶

    In theme customizer: - Dropdown: Compact, good for many options - Pills/Buttons: Visual, good for colors/sizes - Image swatches: Best for colors and patterns

    Step 7: Add Product Reviews (If Applicable)¶

    Social proof increases trust and conversions.

    Enable Reviews¶

    1. Install a review app from Shopify App Store:
    2. Shopify Product Reviews (free)
    3. Judge.me
    4. Loox

    5. Stamped.io

    6. Configure review display on product pages

    7. Enable star ratings
    8. Set up review request emails

    Step 8: Configure Stock Indicators¶

    Help customers understand availability.

    Stock Settings¶

    In theme customizer: - Show inventory: Display stock levels - Low stock threshold: Warning when stock is low - Out of stock: Clear messaging - Pre-order: Enable for upcoming products

    Step 9: Mobile Optimization¶

    Ensure product pages work perfectly on mobile.

    Mobile Checklist¶

    • Images are zoomable on mobile
    • Text is readable without zooming
    • Buttons are easily tappable
    • Variant selectors work smoothly
    • Add to cart button is always visible
    • Product information is organized clearly

    Preview on Mobile¶

    1. In theme editor, use mobile preview mode
    2. Test the entire purchase flow
    3. Check image gallery functionality
    4. Verify button sizes and spacing

    Step 10: Test the Purchase Flow¶

    Before going live, test everything:

    Testing Checklist¶

    • Add product to cart
    • Try different variants
    • Test quantity selector
    • Check dynamic checkout buttons
    • Verify pricing displays correctly
    • Test on multiple devices
    • Check page load speed
    • Verify all images load
    • Test with and without JavaScript

    Best Practices for Product Pages¶

    Content¶

    • Write clear, compelling product titles
    • Use descriptive, benefit-focused copy
    • Include size guides and dimension charts
    • Address common questions in description
    • Add trust signals (free shipping, returns)

    Design¶

    • Keep layout clean and uncluttered
    • Use whitespace effectively
    • Ensure visual hierarchy is clear
    • Make CTA button prominent
    • Maintain brand consistency

    Performance¶

    • Optimize image file sizes
    • Lazy load images below the fold
    • Minimize apps and scripts
    • Enable browser caching
    • Test page speed regularly

    SEO¶

    • Write unique product descriptions
    • Use relevant keywords naturally
    • Optimize image alt text
    • Set up proper meta descriptions
    • Use structured data markup

    Advanced Features¶

    Cross-selling¶

    Set up product bundles or frequently bought together suggestions using apps or metafields.

    Size Guides¶

    Add size guide popups or accordions to help customers choose correctly.

    Product Videos¶

    Upload product videos to showcase features and usage.

    360° Product Views¶

    Use apps to add interactive product rotation.

    Monitoring Performance¶

    Track your product page performance:

    • Conversion rate: Percentage of visitors who purchase
    • Bounce rate: Visitors who leave without action
    • Time on page: How long visitors engage
    • Add to cart rate: Percentage who add to cart
    • Cart abandonment: Who adds but doesn't purchase

    Use Shopify Analytics or Google Analytics to monitor these metrics.
