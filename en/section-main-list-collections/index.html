    List Collections Page Template¶

    The List Collections page displays all your store's collections in a grid, giving customers an overview of all product categories. This page typically appears at /collections.

    Template Settings¶

    Layout¶

    • No margin bottom — Remove bottom spacing below the section. Default: Enabled.
    • Color scheme — Background color and text style. Default: Scheme 1.
    • Pagination color scheme — Color scheme for pagination controls. Default: Scheme 1.

    Display¶

    • Collections per page — How many collections to show before pagination. Range: 1-50. Default: 24.

    How It Works¶

    The page automatically displays: - All published collections in your store - Collection featured images - Collection titles - Links to each collection page

    Collections appear in a responsive grid: - Desktop: 4 columns (col-lg-3) - Tablet: 3 columns (col-sm-4) - Mobile: 2 columns (col-6)

    Collection Cards¶

    Each collection is displayed as a card showing: - Collection featured image - Collection title - Number of products (optional, based on theme settings) - Link to collection page

    Card appearance is controlled by your theme's global collection card settings (Theme Settings > Collection Cards).

    Usage Tips¶

    • Featured images: Add attractive featured images to all collections for visual appeal.
    • Naming: Use clear, descriptive collection names that tell customers what they'll find.
    • Organization: Organize collections logically (by category, season, style, etc.).
    • Homepage link: Add a prominent link to this page from your homepage or main navigation.
    • Collections per page: 24 collections is usually sufficient. Adjust if you have many collections.

    Managing Collections¶

    Collections are managed in your Shopify admin:

    1. Go to Products > Collections
    2. Create, edit, or delete collections
    3. Add featured images
    4. Write descriptions
    5. Set collection rules (manual or automated)

    Changes automatically appear on the List Collections page.

    Best Practices¶

    • High-quality images: Use consistent, professional images for all collections (recommended: 800x800px minimum).
    • Strategic organization: Create collections that match how customers think about your products.
    • Collection descriptions: Add descriptions for SEO—they help search engines understand your collections.
    • Seasonal collections: Update regularly with seasonal or promotional collections to keep content fresh.
    • Navigation: Include a "Shop All" or "All Collections" link in your main menu.

    Common Use Cases¶

    • Main categories: "Men's", "Women's", "Kids"
    • Product types: "Shoes", "Tops", "Accessories"
    • Occasions: "Summer", "Workwear", "Formal"
    • Features: "New Arrivals", "Sale", "Best Sellers"
    • Brands: Collections organized by brand or manufacturer
