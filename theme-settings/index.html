    Theme Settings¶

    This guide explains all the global settings for your Theme InSpire. These settings control the overall appearance and behavior of your entire online store. You can access these settings by going to your Shopify admin, clicking on Online Store > Themes, and then clicking the Customize button on your active theme.

    Once in the Theme Editor, click the theme settings icon (usually in the left sidebar) to access these global options.

    Logo¶

    Configure your store's logo and favicon (the small icon that appears in browser tabs).

    Settings¶

    • Logo — Upload your store's logo image. This will appear in your header and throughout your store.
    • Logo width — Control how wide your logo appears on your site. You can adjust this from 50px to 300px. The default is 100px.
    • Favicon — Upload a small icon (favicon) that will appear in browser tabs when customers visit your store. Your image will automatically be resized to 32x32 pixels.

    Colors¶

    Control the color schemes used throughout your store. You can create multiple color schemes and apply them to different sections.

    Color Schemes¶

    You can define multiple color schemes (combinations of colors that work well together). Each scheme includes:

    • Background color — The main background color for sections using this scheme.
    • Background gradient — Add a gradient effect to the background. This will replace the solid background color if you set one.
    • Title color — The color used for headings and titles.
    • Text color — The color used for body text and paragraphs.
    • Button background — The background color for primary buttons.
    • Button text color — The text color that appears on primary buttons.
    • Secondary outlined button color — The color used for secondary (outline-style) buttons, including their text and border.

    Global Color Settings¶

    • Default color scheme — Select which color scheme to use as the default throughout your store.
    • Body text color — The main color for regular text across your site.
    • Default background color — The background color for your site when no specific scheme is applied.
    • Link text color — The color for clickable text links.
    • Color for borders — The color used for borders and dividing lines throughout your site.
    • Error color — The color used to display error messages (default: red).
    • Warning color — The color used for warning messages (default: yellow/orange).
    • Success color — The color used for success messages (default: green).
    • Informational color — The color used for informational messages (default: blue).

    Typography¶

    Control all the fonts and text sizes used throughout your store.

    Font Selection¶

    • Heading font — Choose the font family for all headings (H1, H2, H3, etc.) across your store.
    • Body font — Choose the font family for regular body text throughout your store.

    Font Sizes - Desktop¶

    Set the size of text for different heading levels when viewed on desktop computers:

    • H1 font size — Size for your largest headings. Range: 10-50px. Default: 36px.
    • H2 font size — Size for secondary headings. Range: 10-50px. Default: 32px.
    • H3 font size — Size for third-level headings. Range: 10-100px. Default: 24px.
    • H4 font size — Size for fourth-level headings. Range: 10-100px. Default: 20px.
    • H5 font size — Size for fifth-level headings. Range: 10-100px. Default: 16px.
    • H6 font size — Size for your smallest headings. Range: 10-100px. Default: 14px.
    • Title 1 font size — Size for display titles (extra large decorative text). Range: 10-50px. Default: 48px.
    • Title 2 font size — Size for secondary display titles. Range: 10-50px. Default: 40px.
    • Body font size — Size for regular paragraph text. Range: 10-30px. Default: 16px.

    Font Sizes - Mobile and Tablet¶

    Set the size of text when viewed on mobile phones and tablets:

    • H1 font size (mobile/tablet) — Range: 10-50px. Default: 28px.
    • H2 font size (mobile/tablet) — Range: 10-50px. Default: 24px.
    • H3 font size (mobile/tablet) — Range: 10-50px. Default: 20px.
    • H4 font size (mobile/tablet) — Range: 10-50px. Default: 18px.
    • H5 font size (mobile/tablet) — Range: 10-50px. Default: 16px.
    • H6 font size (mobile/tablet) — Range: 10-50px. Default: 14px.
    • Title 1 font size (mobile/tablet) — Range: 10-50px. Default: 36px.
    • Title 2 font size (mobile/tablet) — Range: 10-50px. Default: 32px.
    • Body font size (mobile/tablet) — Range: 10-30px. Default: 14px.

    Font Settings¶

    Fine-tune the spacing and appearance of your text:

    • Heading letter spacing — Adjust the space between letters in headings. Use negative values to tighten spacing or positive values to loosen it. Range: -5px to 10px. Default: 0px.
    • Heading line height — Control the vertical space between lines in headings. Higher values create more breathing room. Range: 1 to 2. Default: 1.2.
    • Body letter spacing — Adjust the space between letters in body text. Range: -5px to 10px. Default: 0px.
    • Body line height — Control the vertical space between lines in body text. Higher values improve readability. Range: 1 to 2. Default: 1.8.

    Layout & Styling¶

    Control the overall layout, spacing, and visual style of your store.

    Container Width¶

    • Container width — Set the maximum width of your content area. Range: 1100-1800px. Default: 1300px. Larger values create a wider site, while smaller values create a more compact design.

    Border Radius¶

    Control how rounded the corners are for different elements:

    Sections: * Section border radius — How rounded the corners of sections should be. Range: 0-100px. Default: 30px. * Section radius top — Which top corners should be rounded (None / Both / Left / Right). * Section radius bottom — Which bottom corners should be rounded (None / Both / Left / Right).

    Cards (Product cards, collection cards, etc.): * Card border radius — How rounded the corners of cards should be. Range: 0-30px. Default: 20px. * Card radius top — Which top corners should be rounded (None / Both / Left / Right). * Card radius bottom — Which bottom corners should be rounded (None / Both / Left / Right).

    Buttons: * Button border radius — How rounded button corners should be. Range: 0-30px. Default: 30px. * Button radius top — Which top corners should be rounded (None / Both / Left / Right). * Button radius bottom — Which bottom corners should be rounded (None / Both / Left / Right).

    Shadows¶

    • Card Shadows — Control when shadows appear on cards:
    • None — No shadows
    • On hover — Shadows only appear when you hover over a card
    • Always — Shadows are always visible

    Animation¶

    • Enable entrance animations — When enabled, elements will animate into view as customers scroll down the page. This creates a more dynamic, engaging experience. Note: These animations won't be visible when viewing your site in the Theme Editor.

    Header¶

    Configure how your header (the top bar of your site) appears.

    • Transparent header — Enable this to make the header transparent on your homepage. The header will use the normal background when you scroll down. This works best when your first homepage section is a full-width banner or carousel.
    • Header text color — Choose the color for text and icons when the header is transparent. This ensures your navigation is visible over your homepage hero image. (Only visible when "Transparent header" is enabled)
    • Logo for transparent header — Upload an alternate logo that only shows when the header is transparent. For example, you might use a white logo on the transparent header and your regular colored logo when scrolled. (Only visible when "Transparent header" is enabled)

    Sections¶

    Control the spacing between and within sections throughout your store.

    General - Desktop¶

    Control spacing on desktop computers:

    • Space Within — The padding (internal space) inside sections. This is the space between the section's border and its content. Range: 0-100px. Default: 30px.
    • Space between — The space between sections on all pages. Range: 0-100px. Default: 30px.

    Homepage - Desktop¶

    • Space Between homepage sections — Override the general spacing for sections on the homepage only. Use this if you want tighter or looser spacing on your homepage. Range: 0-100px. Default: 30px.

    General - Phone¶

    Control spacing on mobile phones:

    • Space Within — The padding inside sections on mobile. Range: 0-100px. Default: 15px.
    • Space between — The space between sections on mobile. Range: 0-100px. Default: 0px.

    Homepage - Phone¶

    • Space between homepage sections — Override the general mobile spacing for sections on the homepage only. Range: 0-100px. Default: 0px.

    Product Cards¶

    These settings control how product cards look throughout your store (in collections, search results, product grids, etc.).

    Layout¶

    • Product card color scheme — Choose which color scheme to apply to all product cards.
    • Show border — Enable to show a border around each product card.
    • Text alignment — Choose how text is aligned within product cards (Left / Center / Right).

    Card Features¶

    Choose which information to display on product cards:

    • Show vendor — Display the product's brand or vendor name.
    • Show reviews — Display product review stars (requires a reviews app).
    • Show title — Display the product name.
    • Show price — Display the product price.
    • Show add to cart button — Display a button to add the product to cart directly from the card.
    • Show number input — Display a quantity selector so customers can choose how many to add.
    • Show variants and options — Display product options (like size, color) directly on the card.

    Product Image¶

    • Image Ratio — Control the shape of product images:
    • 1/1 (Square) — Square images
    • ¾ — Portrait (taller than wide)
    • 4/3 — Landscape (wider than tall)
    • 16/9 — Wide landscape
    • 9/16 — Tall portrait

    Product Title¶

    • Title font-size — Choose the size for product titles (H1-size through Body-size). Default: H4-size.
    • Title font-weight — Choose Normal or Bold for product titles. Default: Normal.
    • Title position — Choose whether the title and price appear on one line together, or on separate lines.

    Product Price¶

    • Price font-size — Choose the size for product prices (H1-size through Body-size). Default: H4-size.
    • Price font-weight — Choose Normal or Bold for product prices. Default: Bold.

    Hover Effects¶

    Control what happens when customers hover over a product card:

    • Slightly zoom in on the product card on hover — The entire card will gently zoom when hovered.
    • Show cart options only on hover — The add to cart button and options only appear when hovering. This creates a cleaner look when not hovering.
    • Show a hover effect on product image — The product image will darken and blur slightly on hover, drawing attention to the card.

    Product Badges¶

    Control the badges (labels) that appear on product cards:

    General Badge Settings: * No rounded corners for badges — Disable this to make badges rectangular instead of rounded.

    "New" Badge: * Show 'New' badge — Display a "New" badge on recently added products. * Number of days for 'New' badge — How many days after creation should a product show the "New" badge? Range: 1-60 days. Default: 14 days. * Icon for 'New' badge (optional) — Add an icon from Font Awesome (e.g., "star"). Visit https://fontawesome.com/v6/search for icon names. * Text for 'New' badge — Customize the text shown on the badge. Default: "New". * Background color 'New' badge — Choose the badge background color. Default: Green (#35D39D). * Text color 'New' badge — Choose the text color for the badge. Default: White.

    "Sale" Badge: * Show 'Sale' badge — Display a "Sale" badge when a product has a compare-at price (is on sale). * Type 'Sale' badge — Choose whether to show text (like "Sale") or the discount percentage (like "-20%"). * Icon for 'Sale' badge (optional) — Add an icon from Font Awesome. * Text for 'Sale' badge — Customize the badge text. Default: "Sale". * Background color 'Sale' badge — Choose the badge background color. Default: Red (#EF4D61). * Text color 'Sale' badge — Choose the text color. Default: White.

    Custom Badge (Advanced): * Show custom badge (metafield) — Enable badges controlled by product metafields. This requires setting up product metafields in your Shopify admin. * Icon for 'Custom' badge (optional) — Add an icon from Font Awesome. * Metafield name for custom badge — Enter the name of the product metafield to use (e.g., "custom_badge"). You must create this metafield in Shopify admin under Settings > Metafields > Products. * Color for custom badge — Choose the background color. Default: Yellow (#FFC12E). * Text color custom badge — Choose the text color. Default: White.

    Collection & Brand Cards¶

    Control how collection and brand cards appear throughout your store.

    Layout¶

    • Show collection/brand name — Display the name of the collection or brand on the card.
    • Show border — Display a border around collection and brand cards.

    Collection / Brand Image¶

    • Image Ratio — Control the shape of images:
    • 1/1 (Square)
    • ¾ — Portrait
    • 4/3 — Landscape
    • 16/9 — Wide landscape
    • 9/16 — Tall portrait

    Hover Effects¶

    • Slightly zoom in on the collection/brand card on hover — Cards will gently zoom when customers hover over them.

    Hero Cards¶

    Hero cards are large banner-style cards often used to feature collections or promotions.

    Layout¶

    • Title position — Choose where the title appears on the card:
    • Top — Title at the top of the card
    • Bottom — Title at the bottom of the card
    • Show border — Display a border around hero cards.

    Hover Effects¶

    • Slightly zoom in on the hero card on hover — Hero cards will gently zoom when hovered.

    Social Media¶

    Add links to your social media accounts. These links will appear in sections throughout your store (like your footer) wherever social media icons are enabled.

    Social Media Accounts¶

    • X / Twitter account — Enter your X (Twitter) profile URL. Default: https://www.twitter.com/
    • Facebook account — Enter your Facebook page URL. Default: https://www.facebook.com/
    • Pinterest account — Enter your Pinterest profile URL. Default: https://www.pinterest.com/
    • Instagram account — Enter your Instagram profile URL. Default: https://www.instagram.com/
    • TikTok account — Enter your TikTok profile URL. Default: https://www.tiktok.com/
    • Snapchat account — Enter your Snapchat profile URL. Default: https://www.snapchat.com/
    • YouTube link — Enter your YouTube channel URL. Default: https://www.youtube.com/
    • LinkedIn link — Enter your LinkedIn profile or company page URL. Default: https://www.linkedin.com/
