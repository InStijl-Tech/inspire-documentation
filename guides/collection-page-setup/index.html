    Collection Page Setup Guide¶

    This guide will help you create effective collection pages that help customers discover and browse your products.

    Overview¶

    Collection pages organize your products into browsable categories. Well-designed collection pages should:

    • Display products in an organized, scannable layout
    • Provide filtering and sorting options
    • Show collection descriptions and imagery
    • Load quickly with many products
    • Work seamlessly on all devices

    Understanding Collection Pages¶

    Theme InSpire provides several ways to display collections:

    1. Collection Template - Main collection page with product grid
    2. Collections Grid - Display multiple collections as cards
    3. Collections Carousel - Scrollable collection showcase
    4. Collection List - Directory of all collections

    Step 1: Configure the Collection Template¶

    The collection template is where customers browse products within a collection.

    Access Collection Template¶

    1. Go to Online Store > Themes
    2. Click Customize
    3. Navigate to Collections > Default collection
    4. Configure the collection page settings

    Key Settings¶

    Collection Header: - Show/hide collection title - Display collection description - Add collection image or banner - Configure header layout

    Product Grid: - Set products per row (2, 3, 4, or 5 columns) - Configure mobile columns (1 or 2) - Set spacing between products - Enable/disable quick view

    Filtering & Sorting: - Enable product filters (price, size, color, etc.) - Configure filter display (sidebar or above grid) - Enable sort options (featured, price, bestselling, etc.) - Set default sort order

    Pagination: - Products per page - Pagination style (numbers or load more) - Enable infinite scroll

    For detailed settings, see Collection Page Template Documentation.

    Step 2: Create and Organize Collections¶

    Before setting up collection pages, organize your products into collections.

    Create a Collection¶

    1. In Shopify admin, go to Products > Collections
    2. Click Create collection
    3. Enter collection details:
    4. Title
    5. Description
    6. Image
    7. Collection type (manual or automated)

    Manual Collections¶

    Choose products individually: - Good for curated selections - Full control over product order - Requires manual updates

    Automated Collections¶

    Products are added based on rules: - Products automatically added/removed - Good for large inventories - Examples: "All products under $50", "Red shirts"

    Collection SEO¶

    Optimize each collection: - Write unique descriptions (at least 150 words) - Use relevant keywords naturally - Set page title and meta description - Add alt text to collection images

    Step 3: Design Collection Headers¶

    Create compelling collection headers.

    Collection Banners¶

    1. In the collection template editor
    2. Enable collection image/banner
    3. Upload high-quality banner images (2400px x 600px recommended)
    4. Configure text overlay options
    5. Set banner height and positioning

    Collection Descriptions¶

    Write effective collection descriptions:

    Structure: 

    ## Collection Name

Brief introduction paragraph about the collection and what 
customers can expect to find.

### Why Shop This Collection
- Benefit 1
- Benefit 2
- Benefit 3

Additional context about the products, style, or use cases.

    Tips: - Keep above-the-fold text concise - Use expandable sections for longer content - Include relevant keywords for SEO - Highlight unique selling points

    Step 4: Configure Product Display¶

    Optimize how products appear in collections.

    Product Card Settings¶

    Configure what information displays on each product card:

    • Product image
    • Product title
    • Price (and compare-at price)
    • Vendor
    • Quick add button
    • Color/variant swatches
    • Badges (new, sale, out of stock)
    • Review stars

    Image Settings¶

    • Aspect ratio: Square, portrait, or landscape
    • Hover effect: Second image on hover
    • Image crop: Cover or contain
    • Lazy loading: Enable for performance

    Grid Layout Options¶

    Desktop: - 2 columns: Large product images, detailed view - 3 columns: Balanced (recommended) - 4 columns: More products visible - 5 columns: Maximum density

    Mobile: - 1 column: Detailed view - 2 columns: Standard (recommended)

    Step 5: Set Up Filtering¶

    Help customers find products quickly with filters.

    Enable Product Filters¶

    1. In Shopify admin, go to Online Store > Navigation > Filters
    2. Enable filters for your collections
    3. Choose filter types:
    4. Availability: In stock, out of stock
    5. Price: Price ranges
    6. Product type: Category filters
    7. Vendor: Brand filters
    8. Tags: Custom filters
    9. Options: Size, color, material (from variants)

    Configure Filter Display¶

    In theme customizer: - Filter position: Sidebar or horizontal - Filter style: Checkboxes, swatches, or list - Collapsible sections: Organize many filters - Active filters: Show selected filters - Clear all: Allow quick filter reset

    Filter Best Practices¶

    • Don't overwhelm with too many filters
    • Use clear, descriptive filter labels
    • Show product count per filter option
    • Enable multi-select for same filter type
    • Test on mobile devices

    Step 6: Configure Sorting Options¶

    Let customers sort products their preferred way.

    Available Sort Options¶

    • Featured: Your curated order
    • Best selling: By sales volume
    • Alphabetically (A-Z): By product title
    • Alphabetically (Z-A): Reverse alphabetical
    • Price (low to high): Cheapest first
    • Price (high to low): Most expensive first
    • Date (old to new): Oldest products first
    • Date (new to old): Newest products first

    Set Default Sort¶

    Choose the best default for each collection: - Featured: For curated collections - Best selling: For popular categories - Price (low to high): For budget-focused collections - Date (new to old): For "New arrivals" collections

    Step 7: Optimize Collection Page Performance¶

    Fast-loading pages improve conversion and SEO.

    Performance Tips¶

    Images: - Compress product images - Use appropriate dimensions (800-1000px) - Enable lazy loading - Use modern formats (WebP with JPG fallback)

    Product Count: - Limit products per page (24-48 recommended) - Use pagination or load more - Consider infinite scroll for mobile

    Scripts: - Minimize third-party apps on collection pages - Defer non-critical JavaScript - Optimize filter interactions

    Caching: - Collections are cached by Shopify - Avoid customer-specific content above the fold

    Step 8: Create a Collection List Page¶

    Help customers discover all your collections.

    Set Up List Collections Page¶

    1. Create a page template for all collections
    2. In theme editor, go to Pages > Collection list
    3. Configure display:
    4. Grid columns
    5. Collection image size
    6. Show product count
    7. Show collection description

    For detailed settings, see List Collections Documentation.

    Step 9: Add Collections to Homepage¶

    Drive traffic to collections from your homepage.

    Using Collections Grid¶

    1. On homepage, add Collections Grid section
    2. Select featured collections
    3. Configure grid layout
    4. Add section heading and description

    For detailed settings, see Collections Grid Documentation.

    Using Collections Carousel¶

    1. On homepage, add Collections Carousel section
    2. Select collections to feature
    3. Configure carousel settings
    4. Enable autoplay (optional)

    For detailed settings, see Collections Carousel Documentation.

    Step 10: Mobile Optimization¶

    Ensure collection pages work perfectly on mobile.

    Mobile Checklist¶

    • Product images are crisp and clear
    • Text is readable without zooming
    • Filters are easily accessible
    • Sort dropdown works smoothly
    • Products load quickly
    • Add to cart is functional
    • Grid layout is appropriate (1-2 columns)
    • Images maintain aspect ratio

    Mobile-Specific Features¶

    • Sticky filter/sort button
    • Slide-out filter drawer
    • Infinite scroll or load more
    • Quick view functionality
    • Optimized image sizes

    Best Practices for Collection Pages¶

    Organization¶

    • Create logical collection hierarchy
    • Use clear, descriptive collection names
    • Limit number of top-level collections (5-10)
    • Use subcollections for large catalogs

    Content¶

    • Write unique descriptions for each collection
    • Add high-quality collection images
    • Include keywords for SEO
    • Highlight collection benefits

    Navigation¶

    • Add collections to main menu
    • Use mega menu for many collections
    • Include breadcrumbs
    • Link related collections

    User Experience¶

    • Show relevant filters only
    • Provide clear sort options
    • Display product availability
    • Enable quick add to cart
    • Show variant options on cards

    Advanced Collection Features¶

    Seasonal Collections¶

    Create seasonal or promotional collections: - "Summer Sale" - "Holiday Gift Guide" - "New Arrivals"

    Update featured collections regularly.

    Smart Collections¶

    Use automated collections with rules: - Products tagged "bestseller" - Products with inventory > 0 - Products added in last 30 days - Products in specific price ranges

    Collection Metafields¶

    Add custom data to collections: - Banner text overlay - Custom icons - Featured content - Related collections

    Monitoring Collection Performance¶

    Track metrics to optimize:

    • Views: How many people visit
    • Bounce rate: Visitors who leave immediately
    • Products viewed: Engagement with products
    • Add to cart rate: How many add products
    • Conversion rate: Percentage who purchase

    Use Shopify Analytics to identify: - Top-performing collections - Collections needing improvement - Effective filter combinations - Optimal product count per page

    Testing Your Collection Pages¶

    Before launching:

    1. Test on multiple devices:
    2. Desktop (various browsers)
    3. Tablet (portrait and landscape)

    4. Mobile (iOS and Android)

    5. Test functionality:

    6. All filters work correctly
    7. Sorting changes product order
    8. Pagination loads properly
    9. Images load correctly

    10. Add to cart functions

    11. Check performance:

    12. Page load time under 3 seconds
    13. Images load progressively

    14. No layout shifts

    15. Verify SEO:

    16. Unique meta descriptions
    17. Proper heading structure
    18. Alt text on images
    19. Clean URLs
