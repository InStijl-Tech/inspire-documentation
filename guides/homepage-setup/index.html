    Homepage Setup Guide¶

    This guide will walk you through creating an engaging and effective homepage for your store using Theme InSpire.

    Overview¶

    A well-designed homepage should:

    • Capture visitors' attention immediately
    • Showcase your best products or collections
    • Communicate your brand message
    • Guide visitors to key areas of your store

    Step 1: Plan Your Homepage Layout¶

    Before you start building, plan your homepage structure. A typical homepage might include:

    1. Hero section (banner with call-to-action)
    2. Featured collections or products
    3. Brand story or unique value proposition
    4. Product carousels
    5. Testimonials or social proof
    6. Newsletter signup or contact form

    Step 2: Add a Hero Section¶

    The hero section is the first thing visitors see.

    Using the Hero Section¶

    1. In the theme editor, click Add section
    2. Select Banners (Hero) from the list
    3. Configure the hero section:
    4. Upload a high-quality hero image or video
    5. Add compelling headline text
    6. Write a supporting subheadline
    7. Add a call-to-action button

    Best Practices: - Use high-resolution images (at least 1920px wide) - Keep text concise and impactful - Use contrasting colors for buttons - Ensure mobile responsiveness

    For detailed settings, see Hero Section Documentation.

    Step 3: Showcase Featured Collections¶

    Help visitors discover your products by featuring collections.

    Add Collections Grid¶

    1. Click Add section
    2. Select Collections Grid
    3. Choose which collections to display
    4. Configure the grid layout (2, 3, or 4 columns)
    5. Add section heading and description

    For detailed settings, see Collections Grid Documentation.

    Add Collections Carousel¶

    Alternatively, use a carousel for more collections:

    1. Click Add section
    2. Select Collections Carousel
    3. Select collections to include
    4. Configure carousel settings (autoplay, speed, etc.)

    For detailed settings, see Collections Carousel Documentation.

    Step 4: Display Featured Products¶

    Highlight your best-selling or featured products.

    Add Products Carousel¶

    1. Click Add section
    2. Select Products Carousel
    3. Choose products to feature (manual or automatic selection)
    4. Configure display settings
    5. Set carousel behavior

    For detailed settings, see Products Carousel Documentation.

    Add Products Grid¶

    For a static grid layout:

    1. Click Add section
    2. Select Products Grid
    3. Select products or choose a collection
    4. Configure grid columns and spacing

    For detailed settings, see Products Grid Documentation.

    Step 5: Add Brand Content¶

    Communicate your brand story and values.

    Using the Content Section¶

    1. Click Add section
    2. Select Content Section
    3. Add your content:
    4. Heading and description
    5. Images or media
    6. Call-to-action buttons
    7. Custom styling

    For detailed settings, see Content Section Documentation.

    Step 6: Build Trust with Testimonials¶

    Social proof helps convert visitors into customers.

    1. Click Add section
    2. Select Testimonials
    3. Add customer testimonials:
    4. Customer name
    5. Testimonial text
    6. Star rating
    7. Customer photo (optional)

    For detailed settings, see Testimonials Documentation.

    Step 7: Highlight Key Features¶

    Show what makes your store special.

    1. Click Add section
    2. Select Icons/Features
    3. Add feature items:
    4. Icon
    5. Feature title
    6. Short description
    7. Common features: Free shipping, Returns, Support, Secure payment

    For detailed settings, see Icons Section Documentation.

    Step 8: Add a Contact Form (Optional)¶

    Make it easy for visitors to reach you.

    1. Click Add section
    2. Select Contact Form
    3. Configure form fields
    4. Set confirmation message
    5. Configure email notifications

    For detailed settings, see Contact Form Documentation.

    Step 9: Arrange Section Order¶

    Optimize the flow of your homepage:

    1. Hover over any section in the theme editor
    2. Use the drag handle (six dots) to reorder sections
    3. Test the flow from a visitor's perspective

    Recommended Order: 1. Hero/Banner 2. Featured Collections 3. Featured Products 4. Brand Story/Content 5. Testimonials 6. Icons/Features 7. Newsletter/Contact

    Step 10: Preview and Publish¶

    Before publishing your changes:

    1. Use the preview modes to test:
    2. Desktop view
    3. Tablet view
    4. Mobile view
    5. Check all links and buttons work
    6. Verify images load correctly
    7. Test forms (if added)
    8. Click Save to publish your changes

    Tips for an Effective Homepage¶

    • Keep it focused: Don't overwhelm visitors with too many sections
    • Mobile-first: Ensure everything looks great on mobile devices
    • Fast loading: Optimize images for web (use compressed formats)
    • Clear CTAs: Make it obvious what you want visitors to do
    • Update regularly: Keep content fresh and relevant
    • A/B test: Try different layouts to see what converts best
