    Getting Started with Theme InSpire¶

    Welcome to Theme InSpire! This guide will help you understand how to customize your theme and build your online store.

    Understanding the Shopify Theme Customizer¶

    All theme customization happens in the Shopify Theme Editor, a visual interface where you can see your changes in real-time.

    How to Access the Theme Editor¶

    1. Log in to your Shopify Admin
    2. Go to Online Store → Themes
    3. Find "Theme InSpire" and click Customize

    Live Preview

    The theme editor shows a live preview of your store as you make changes. Changes are not visible to customers until you click Save.

    Theme Customization Structure¶

    Theme InSpire uses three levels of customization:

    1. Theme Settings (Global)¶

    Location: Click the theme icon or "Theme settings" in the left sidebar (at the bottom)

    Theme Settings control the global appearance of your entire store:

    • Colors - Primary colors, backgrounds, text colors, color schemes
    • Typography - Fonts for headings and body text
    • Layout - Container widths, spacing, grid gaps
    • Product Cards - How products appear throughout your store
    • Buttons - Button styles, hover effects
    • Animations - Enable/disable animations and effects
    • Social Media - Social media links and icons
    • Cart - Cart drawer settings and behavior
    • Search - Search functionality settings

    Global Changes

    Theme Settings affect your entire store. For example, changing the primary color will update it everywhere.

    📚 Learn more: Complete Theme Settings Guide

    2. Sections (Page Layout)¶

    Location: Click any page area in the preview, or use the left sidebar to add/manage sections

    Sections are large building blocks that make up your pages:

    • Each page is built from multiple sections (Header, Hero, Products, Footer, etc.)
    • You can add, remove, reorder, and customize sections
    • Different page types (homepage, product page, collection page) have different available sections

    How to work with sections:

    1. In the theme editor, scroll to where you want to add a section
    2. Click the + Add section button
    3. Choose from available sections (Hero, Products Carousel, Testimonials, etc.)
    4. The section appears on your page
    5. Click the section to customize its settings
    1. In the left sidebar, find the section you want to move
    2. Click and hold the ⋮⋮ (grip) icon
    3. Drag the section up or down
    4. Release to drop it in the new position
    1. Click the section in the left sidebar
    2. Scroll down in the section settings
    3. Click Remove section
    4. Confirm the removal
    1. Click the section (in preview or sidebar)
    2. Adjust settings in the right panel:
      • Heading text and styling
      • Layout options
      • Content (text, images, products)
      • Colors and spacing
      • Visibility settings

    3. Blocks (Section Content)¶

    Location: Inside section settings, under the "Content" or similar heading

    Blocks are small content pieces inside sections:

    • A section can contain multiple blocks
    • Examples: Individual testimonials, feature icons, slides in a carousel
    • Each block has its own settings

    How to work with blocks:

    1. Open a section's settings
    2. Find the blocks area (usually labeled "Content" or "Blocks")
    3. Click + Add block
    4. Choose the block type
    5. Configure the block settings
    1. In the blocks list, click and hold ⋮⋮
    2. Drag to reorder
    3. Release to place
    1. Click the block in the list
    2. Scroll to the bottom of block settings
    3. Click Remove block

    Example: The Testimonials section contains multiple "Testimonial" blocks - one for each customer review.

    Understanding Color Schemes¶

    Color schemes let you create different color combinations for different sections, giving your store visual variety.

    What are Color Schemes?¶

    Think of color schemes as color palettes you can switch between:

    • Scheme 1 might be your brand's primary colors (e.g., orange header, white background)
    • Scheme 2 might be inverted (e.g., dark background, light text)
    • Scheme 3 might be accent colors (e.g., grey background, orange accents)

    How to Create Color Schemes¶

    1. Go to Theme Settings → Colors
    2. You'll see multiple color scheme options (Scheme 1, Scheme 2, Scheme 3, etc.)
    3. For each scheme, set:
      • Background - Main background color
      • Text - Primary text color
      • Button - Button background color
      • Button text - Text on buttons
      • Accent colors - Additional colors for highlights

    Color Scheme Strategy

    Create 2-3 distinct color schemes and alternate them throughout your store for visual interest.

    How to Apply Color Schemes to Sections¶

    1. Open any section settings
    2. Look for Color scheme dropdown
    3. Select from your available schemes (Scheme 1, 2, 3, etc.)
    4. The section instantly updates with those colors

    Example Use Cases:

    • Homepage alternating: Banner (Scheme 1) → Products (Scheme 2) → Testimonials (Scheme 1) → Newsletter (Scheme 2)
    • Product pages: Main product section (Scheme 1) → Related products (Scheme 2)
    • Headers/Footers: Dark color scheme for visual separation

    Step-by-Step: Building Your Store¶

    Follow these steps to set up your store with Theme InSpire:

    Step 1: Configure Global Theme Settings¶

    Time: 15-30 minutes

    1. Open the theme editor (Online Store → Themes → Customize)
    2. Click Theme settings in the left sidebar (scroll to bottom)
    3. Configure these key areas:
    Setting What to Do
    Colors Set up 2-3 color schemes with your brand colors
    Typography Choose fonts that match your brand
    Layout Set your preferred content width (1200px - 1600px)
    Product Cards Choose how products display (image ratio, show price, etc.)
    Buttons Configure button style and hover effects
    Social Media Add your social media links
    1. Click Save to preserve your settings

    Checkpoint

    Your brand colors and fonts are now set globally!

    Step 2: Design Your Homepage¶

    Time: 1-2 hours

    The homepage is your store's first impression. Build it section by section:

    A. Header Setup¶

    1. Click Header section
    2. Set your logo (upload your logo image)
    3. Configure navigation menu
    4. Set header style (sticky, transparent, etc.)
    5. Choose color scheme

    📚 Header Documentation

    B. Hero Section¶

    1. Click + Add section at the top
    2. Choose Hero or Image Banner
    3. Upload a high-quality hero image
    4. Add headline and call-to-action
    5. Link your primary button

    📚 Hero Section Documentation

    C. Featured Products¶

    1. Add Products Carousel or Products Grid section
    2. Choose products to feature (new arrivals, bestsellers)
    3. Set layout (how many products to show)
    4. Apply a color scheme
    5. Add heading text

    📚 Products Carousel | Products Grid

    D. Content Sections¶

    Add sections that tell your story:

    • Image with Text - Showcase your brand story
    • Icons/Features - Highlight key benefits (free shipping, quality, etc.)
    • Testimonials - Build trust with customer reviews
    • Image Carousel - Display multiple images

    E. Footer¶

    1. Click Footer section
    2. Add footer blocks (links, newsletter, contact info)
    3. Set social media links
    4. Configure copyright text

    📚 Footer Documentation

    Visual Flow

    Alternate color schemes between sections for a dynamic, professional look.

    Step 3: Set Up Product Pages¶

    Time: 30-45 minutes

    1. In the theme editor, navigate to Products → Select any product
    2. This shows the product page template
    3. Configure these sections:
    Section Purpose
    Product Information Main product details, price, add to cart
    Product Description Detailed product information with tabs
    Product Specifications Technical specs in table format
    Product Recommendations Related or complementary products
    1. Add blocks inside sections (e.g., trust badges, size guides)
    2. Set image gallery style
    3. Configure variant selectors

    📚 Product Page Guide

    Step 4: Configure Collection Pages¶

    Time: 20-30 minutes

    1. Navigate to Collections → Select any collection
    2. Configure collection page layout:
      • Filters - Enable/disable product filtering
      • Sort options - Allow sorting by price, name, etc.
      • Grid - Set products per row (2, 3, 4 columns)
      • Product card style - From Theme Settings
    3. Add optional sections:
      • Collection banner
      • Collection description

    📚 Collection Page Guide

    Step 5: Design Additional Pages¶

    Time: 1-2 hours

    Create and customize these important pages:

    About Page¶

    1. Go to Pages → Create or select "About"
    2. Add sections:
      • Hero/Banner with team photo
      • Content sections with your story
      • Image carousel with photos
      • Testimonials

    Contact Page¶

    1. Go to Pages → Create or select "Contact"
    2. Add Contact Form section
    3. Include store location, hours, contact details

    📚 Contact Form Documentation

    Blog¶

    1. Navigate to Blog posts in theme editor
    2. Customize blog listing page
    3. Customize article template
    4. Set featured image style

    📚 Blog Guide | Article Guide

    Step 6: Configure Cart & Checkout¶

    Time: 15-20 minutes

    1. Go to Theme Settings → Cart
    2. Choose cart type:
      • Drawer - Side panel that slides in
      • Page - Dedicated cart page
    3. Enable cart features:
      • Cart notes
      • Shipping calculator
      • Cross-selling recommendations
    4. Customize cart messaging

    📚 Cart Documentation

    Step 7: Mobile Optimization¶

    Time: 20-30 minutes

    1. In theme editor, click the mobile preview icon (top toolbar)
    2. Check each page on mobile view
    3. Adjust mobile-specific settings:
      • Mobile menu style
      • Mobile image sizes
      • Stack order on mobile
      • Font sizes
    4. Test navigation and buttons

    Mobile Traffic

    Over 70% of e-commerce traffic is mobile. Always preview mobile!

    Step 8: Test & Launch¶

    Time: 30-60 minutes

    Before going live, test everything:

    • Add a product to cart and complete checkout
    • Test all navigation links
    • Submit the contact form
    • Test search functionality
    • Try filtering on collection pages
    • Check all pages on mobile
    • Verify social media links
    • Test newsletter signup
    • Review all images (proper sizing, fast loading)
    • Check spelling and grammar

    Final Steps:

    1. Click Save in the theme editor
    2. If theme is not live: Actions → Publish
    3. Visit your live store and verify everything works
    4. Share with friends for feedback

    Congratulations!

    Your Theme InSpire store is now live! 🎉

    Tips for Success¶

    Design Best Practices¶

    Visual Hierarchy

    • Use larger fonts for important headings
    • Alternate between light and dark sections
    • Keep 3-5 sections max on homepage above the fold
    • Use whitespace generously

    Color Usage

    • Stick to 2-3 main colors throughout
    • Use contrasting colors for call-to-action buttons
    • Ensure text is readable against backgrounds
    • Keep color schemes consistent

    Content Strategy

    • Use high-quality product photos (1200x1200px minimum)
    • Write compelling product descriptions
    • Include customer testimonials
    • Add trust badges (secure checkout, money-back guarantee)

    Performance Tips¶

    • Optimize images - Use Shopify's image compression
    • Limit sections - Don't add too many sections per page
    • Test speed - Use Google PageSpeed Insights
    • Enable lazy loading - In Theme Settings → Performance

    Common Questions¶

    Can I change colors after setting them up?

    Yes! Go back to Theme Settings → Colors anytime to update your color schemes. Changes apply instantly across your store.

    How many sections can I add to a page?

    There's no hard limit, but for performance, keep homepage to 8-12 sections max. More sections = slower loading.

    Can I use different layouts on different pages?

    Yes! Use templates. In Theme Settings, you can create multiple page templates with different section combinations.

    What if I make a mistake?

    The theme editor has an undo button (top left). You can also duplicate your theme before making major changes: Online Store → Themes → Actions → Duplicate.

    How do I add new products to a section?

    Most product sections let you choose products manually or automatically (by collection). In section settings, look for "Products" or "Collection" options.

    Can customers see my changes as I make them?

    No! Changes in the theme editor are only visible to you. Click Save when ready, and only then will customers see updates.
