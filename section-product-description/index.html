    Product Description Section¶

    The Product Description section displays the detailed product description on your product pages. It shows the full description you've entered in your Shopify admin, along with optional title, icons, and app integrations.

    This section is specifically designed for product pages and helps customers understand what they're buying.

    Important Note¶

    This section only appears on product pages. You customize it by: 1. Going to your Theme Editor 2. Navigating to any product page (or selecting "Products" > "Default product") 3. Finding the Product Description section 4. Adjusting settings or adding blocks

    The actual product description content is managed in your Shopify admin under Products.

    Section Settings¶

    Layout¶

    • No margin bottom — Enable to remove the bottom spacing below this section (useful if you're stacking multiple product sections closely together). Default: Enabled.

    • Color scheme — Choose the background color and text style. Default: Scheme 1.

    Text Settings¶

    • Text alignment — Align the description text:
    • Left — Left-aligned (standard for readability)
    • Center — Centered
    • Right — Right-aligned

    Default: Left.

    Blocks¶

    Title Block¶

    Add an optional title above the product description. Limit: 1 title block.

    Settings:

    • Heading — The title text to display. Default: "Information & Details".

    • Heading tag — Choose the HTML tag for SEO:

    • H1-H6 — Standard heading tags
    • Span — Not a heading (for styling only)

    Default: H2.

    Tip: Choose the tag based on your SEO strategy. This doesn't affect the visual size.

    • Heading size — Control the visual size of the title:
    • Title 1 — Largest
    • Title 2 — Large
    • H1-H6 — Standard sizes

    Default: H2.

    • Heading font weight — Text thickness. Range: 100 (thin) to 900 (bold). Default: 700 (bold).

    Icon Block¶

    Add icon blocks to highlight key product features or benefits below the description. These appear in a centered grid below your description text.

    Settings for each Icon:

    • Icon — Font Awesome icon code (e.g., fa-solid fa-truck-fast). Default: "fa-solid fa-check".

    • Find icons at fontawesome.com

    • Heading — Title for this feature. Example: "Fast Shipping".

    • Text — Description text explaining the feature.

    Icons automatically display in a responsive grid (up to 4 columns on desktop, stacking on mobile).

    App Block¶

    Integrate third-party Shopify apps into your product description area. Apps that support product page blocks will appear as options when you add an App block.

    Managing Product Descriptions¶

    The actual product description content is managed in your Shopify admin:

    1. Go to Products in your Shopify admin
    2. Select the product you want to edit
    3. Scroll to the Description field
    4. Enter your product description using the rich text editor
    5. Save your changes

    The theme automatically displays this description in the Product Description section.

    Usage Tips¶

    • Clear structure: Use the title block to add a heading like "Product Details" or "About This Product" to visually separate the description from other page elements.

    • Formatting: Format your product descriptions in the Shopify admin with:

    • Bullet points for features
    • Bold text for emphasis

    • Short paragraphs for readability

    • Icon features: Use icon blocks to highlight important selling points:

    • Shipping and delivery
    • Warranty or guarantees
    • Quality certifications
    • Return policy

    • Customer support

    • Icon selection: Choose icons that clearly represent each feature. Keep icons consistent in style (all solid or all outlined).

    • Don't duplicate: The description automatically pulls from your product data—you don't need to retype it in the theme settings.

    • Mobile readability: Long paragraphs are hard to read on mobile. Break content into shorter chunks with headings and lists.

    • App integrations: Many review apps, size charts, and product enhancement apps can be added via the App block.

    • SEO considerations: Use the heading tag setting strategically. If your product title is H1, make the description title H2 for proper heading hierarchy.

    Best Practices¶

    • Be descriptive: Help customers make informed decisions by explaining:
    • What the product is and what it does
    • Key features and specifications
    • Materials and quality
    • Sizing or compatibility information

    • Care instructions

    • Tell a story: Beyond just listing features, explain how the product benefits the customer and solves their problem.

    • Use keywords naturally: Include relevant search terms customers might use, but write for humans first.

    • Keep it scannable: Use short paragraphs, bullet points, and subheadings to make information easy to find.

    • Update regularly: Refresh descriptions as you learn what questions customers ask or what features they care about most.

    Common Icon Block Examples¶

    • Shipping: fa-solid fa-truck + "Free Shipping Over $50"
    • Returns: fa-solid fa-rotate-left + "30-Day Easy Returns"
    • Warranty: fa-solid fa-shield-halved + "1-Year Warranty Included"
    • Quality: fa-solid fa-certificate + "Premium Quality Materials"
    • Support: fa-solid fa-headset + "24/7 Customer Support"
    • Secure: fa-solid fa-lock + "Secure Checkout"
